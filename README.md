## Project Overview

This project demonstrates the practical implementation of JavaScript fundamentals through an interactive learning dashboard.

The project covers:

- JavaScript Functions
- Arrays
- Objects
- DOM Manipulation
- JavaScript Events
- A Mini Project – Student Record Manager

The goal of this project is to demonstrate how JavaScript can make a webpage interactive and dynamic.

The project demonstrates:

- Function declarations
- Parameters
- Arguments
- Return values
- Multiple functions
- Arrow functions

### Practical Examples

- Personalized greeting generator
- Marks and percentage calculator
- Grade calculation
- Two-number addition using an arrow function

## Task 2 – JavaScript Arrays

The project demonstrates:

- Creating arrays
- Accessing array elements
- Adding elements using `push()`
- Removing elements using `pop()`
- Updating array elements
- Iterating using `forEach()`
- Checking elements using `includes()`
- Displaying arrays using `join()`

### Practical Example

A student names array allows users to add, remove, update, access and iterate through student names.
